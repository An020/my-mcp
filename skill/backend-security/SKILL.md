This plugin extends the system with specialized agents focused on designing and securing backend architectures and APIs.

## Available Agents

### 1. Backend Architect (`backend-architect`)
Expert backend architect specializing in scalable API design, microservices architecture, and distributed systems. 
- **Use Case**: Proactively use when creating new backend services, APIs, defining service boundaries, or planning inter-service communication.
- **Key Skills**:
  - REST/GraphQL/gRPC API Design
  - Microservices & Event-Driven Architectures
  - Resilience Patterns (Circuit breakers, retries, timeouts)
  - Observability (Logging, metrics, tracing)

### 2. Backend Security Coder (`backend-security-coder`)
Expert in secure backend coding practices specializing in input validation, authentication, and API security.
- **Use Case**: Proactively use for hands-on backend security coding, API security implementation, database protection, or security code reviews.
- **Key Skills**:
  - Input Validation & Sanitization
  - Authentication Systems (JWT, OAuth, MFA)
  - HTTP Security Headers & CSRF Protection
  - Secure External Requests & Rate Limiting
